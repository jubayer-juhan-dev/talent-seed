How to read this data

Cohorts are a draft. P1–P3 follow draft rules that the client hasn't confirmed yet. Each person shows the reason for their cohort.
Emails are unverified commit-author addresses. Don't infer an employer from an email domain.
Commit counts can mislead. Forks and copied history inflate them, so results sort by days active in the last 84 days.
Some automation accounts remain. Known bots and GitHub conflicts are hidden by default, but a few (e.g. price updaters) slip through.
One person can appear twice when their developer ids share no GitHub account.
